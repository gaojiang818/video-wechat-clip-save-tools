    - **OKR管理定制系统**
        - 功能定位：替代通用SaaS OKR工具，适配古茗内部管理逻辑，支持部门OKR向下认领、预算进度关联、跨部门 workload 统一看板。

        - 功能定位：替代原数十人设计师团队的新品操作视频生产工作，适配古茗高频上新、配方动态调整的业务需求。
        - 流程重构逻辑：AI先基于历史脚本生成动画框架、输出实拍任务清单，员工按要求拍摄素材后，一键生成剪映工程文件。
        - 提效成果：大幅降低视频生产的返工率，适配新品配方动态调整的需求，整体生产效率较原人工模式提升数倍。
    - **门店培训互动游戏**
        - 功能定位：将原线下卡牌培训转化为线上互动对战小游戏，设置排行榜与大屏对战场景，嵌入加料标准、代言人认知等培训内容。
        - 落地价值：提升门店员工培训的趣味性与参与度，AI自动统计高频出错点，为培训导师调整课纲提供数据支撑。
    - **会议全流程提效工具**
        - 功能定位：打通飞书日历与妙记，自动归集单场会议的所有录音、文档资料，AI自动提炼会议结论、生成标准化待办。
        - 扩展能力：支持跨会议上下文关联，自动为用户生成会前准备文档，还可提供个人会议表现的优化建议，后续将开源相关Skill。
    - **AI落地方法论**
        - 主水管与小水龙头逻辑：企业AI落地既要搭建统一数据源、权限体系的主水管，也要支持员工自主使用AI工具的小水龙头。
        - 人员分层逻辑：企业内部AI使用人群可分为三层，70%的人需要标准化工具支持，20%的人可自主探索工具，10%的人负责搭建公共工具。
        - 高效开发技巧：优先用GPT生图工具生成系统界面原型，确认样式后再交由Codex生成代码，大幅降低前端开发的试错成本。
- **郑博文（Bowen）：Wonderlab AI落地实践**
    - **核心落地方法论**
        - 业务转化逻辑：将公司30多个业务部门的经验、流程拆解为AI可执行的Skill，再组合为可协同、可迭代的Agent，实现组织级AI提效。
        - 需求校验Skill：针对AI开发中频繁出现的假设偏差、需求模糊问题，开发覆盖四类已知/未知场景的全流程需求校验工具，较同类工具更轻量化。
        - 工具价值：将模糊的业务需求转化为可验证的开发任务，提前识别返工风险，覆盖从需求调研到上线交付的全流程。
    - **内部落地反馈**
        - 已落地的AI辅助招聘体系，将候选人简历、面试信息自动转化为结构化评估报告，HR可按需提取关注维度的分析内容。
        - 相关工具上线后内部使用需求激增，已消耗完基础版ID额度，后续需增购更高版本的服务，员工接受度与使用意愿极高。
        - 核心原则：AI仅提供辅助决策建议，最终决策权始终保留在人手中，既避免决策责任风险，也保留人文判断的灵活性。
- **FDE岗位认知与企业落地建议**
    - **温晨的分享建议**
        - 能力成长路径：先锚定单一AI博主建立基础认知，避免被多元信息干扰，再逐步拓展学习其他内容，重点深入业务一线积累实操经验。
        - 岗位配置必要性：当前阶段规模型企业均应设置该岗位，既可以直接产出落地提效工具，也能带动内部整体的AI使用氛围。
    - **张岚焱的分享建议**
        - 核心素质要求：要具备跳出现有工作流的AI原生思维，敢于提出创新需求，相信AI的实现能力，同时搭建可复用的个人上下文体系。
        - 长期发展趋势：未来企业内部系统将逐步弱化固定界面，核心能力是支持Agent直接接入调用，实现系统能力的最大化复用。
    - **郑博文的分享建议**
        - 核心能力排序：第一优先级是强沟通表达与需求理解能力，其次是技术背景与架构思维，最后是多线程任务处理能力。
        - 落地避坑提示：AI仅提升开发速度，不会自动保障系统的稳定性、安全性与合规性，非技术背景人员搭建的系统易出现隐性问题。
    - **会议后续安排**

## 可复用要点（从全文与官方摘要提炼）

### 温晨 / 歌力思·劳芮

- **芮观**：店长 / 负责人 / 商品三端经营罗盘；自定义看板；人货场 AI 建议；多源数据清洗 + 三方交叉校验；飞书分时段推送；全品牌店长已用；看数从 1.5–2h → 约 1 分钟。
- **睿算**：复杂门店薪资；核心核算硬编码保确定性，AI 辅复核/语音核对；HR 算薪约 7 天 → 不到 1 分钟量级。
- **FDE 实践**：下店问卷挖痛点；约 4 个月、~36 万行代码单人 vibe coding；工具必须获业务真实认可。

### 张岚焱 / 古茗

- **定制 OKR**：通用 SaaS 不适配 → 自建；Skill 对接 Agent；打通周报/周会；「主水管 vs 小水龙头」。
- **新品教学视频**：AI 动画框架 + 实拍清单 → 剪映草稿包；降返工。
- **加料卡牌培训游戏**：线上/大屏对战、错题回流导师。
- **会议助手 Skill**（打磨中拟开源）：日历+妙记归集、会前准备、会后待办；Codex + 飞书数据。
- **开发技巧**：先生图确认 UI 再 Codex；敢许愿 + AI-native 重设流程。

### 郑博文 / Wonderlab

- 协同 30+ 业务部门：经验 → Skill → 可协同 Agent。
- 需求校验 Skill：覆盖已知/未知四类认知场景，降假设偏差。
- AI 辅助招聘等已落地；**AI 只做决策参考，最终权在人**。
- FDE 素质排序：沟通/理解业务 > 技术架构（防 vibe coding 不稳）> 多线程切换能力。

### 主持人 / 共识

- 规模型传统企业需要专人（FDE/AIBP 等名称不重要）深入业务推 AI。
- 飞书已支持 Agent 入会：可听会实时执行任务（发言仍为真人）。
- 回放与资料发会议群 / 粉丝群。
